==============================================================
  DyslexiaQuest - Local Host Setup Instructions
==============================================================

REQUIREMENTS:
- Node.js (Version 18 or higher)
  If you don't have Node.js installed, download it for free from:
  https://nodejs.org/ (Recommended: LTS version)

--------------------------------------------------------------
HOW TO RUN THE SITE ON YOUR LAPTOP:
--------------------------------------------------------------

OPTION 1: One-Click Launcher (Windows)
1. Extract this entire zip file to any folder on your laptop.
2. Double-click the file named:
   start_app.bat
3. It will automatically install the packages (first time only) and launch the server.
4. Look at the terminal for the Local link (usually http://localhost:5173/ or http://localhost:5174/) and open it in your web browser (Chrome, Edge, Brave, etc.).

OPTION 2: Manual Terminal / VS Code / Command Prompt
1. Extract the zip file to your preferred folder.
2. Open Command Prompt, PowerShell, or Terminal inside that folder.
3. Type:
   npm install
   (Wait for packages to finish downloading)
4. Type:
   npm run dev
5. Press Enter. You will see output like:
   Local:   http://localhost:5173/
6. Open that URL in your browser!

Enjoy exploring the Lost Canopy of Lexis!
